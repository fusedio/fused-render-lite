# Apple Notes draft a new note
trigger: add a note, create a note, save this to notes, write a note, put in my notes, jot down, new note in

1. goto https://www.icloud.com/notes/ and `wait` for the folder list. If a sign-in, 2FA or trust page appears, use `login`.
2. Click the folder the task names (default: Notes). Do not click the new-note button yet.
3. Compose the note from the task: first line becomes the title, then the body; keep the user's wording. Show the user the folder, title and full body and proceed only after approval, since Notes saves while typing and there is no Send step to stop at.
4. After approval click the new-note button (the pencil-in-square icon above the editor), `type` the text into the editor, then `wait` 3 seconds and `read` the note list to confirm the new title appears with today's date.
5. Report the folder and title created and the body as saved. If approval was refused, create nothing and say so.
